## 📌 Proyectos destacados

### 📡 Detección y seguimiento de objetos mediante LiDAR

Sistema cliente-servidor desarrollado en **C++** para procesar nubes de puntos, detectar objetos y analizar su movimiento en tiempo real.

Tecnologías principales:

`C++` · `PCL` · `TCP/IP` · `RoboSense LiDAR` · `Ubuntu`

---

### 🔐 Detector de phishing

Herramienta para analizar correos electrónicos, enlaces, dominios, cabeceras y patrones sospechosos con el objetivo de detectar posibles ataques de phishing.

Tecnologías principales:

`Python` · `Streamlit` · `BeautifulSoup` · `Email Analysis`

---

### ♟️ Herramientas para ajedrez

Desarrollo de aplicaciones orientadas a clubes y jugadores de ajedrez: análisis de rivales, consulta de partidas, variaciones de ELO y gestión de información competitiva.

Tecnologías principales:

`Python` · `JavaScript` · `APIs` · `Análisis de datos`
